Previous audit

Completed for the recorded stock and CP browser coverage. Confirmed Angular behavior gaps are fixed and deployed; unavailable flows and remaining visual variation are documented below.

Baseline is Nuxeo Web UI. The Angular core and CP Angular layouts are the implementation targets. Before captures came from Web UI 2025.21.1, Angular 3.21.3 and CP 1.0.29, on backend 2025.20-SNAPSHOT.

Final release targets: Web UI 2025.21.3, Angular 3.21.7, SDK 0.1.2 and CP 1.0.33. Source tests do not establish deployed parity; the final record below tracks runtime verification separately.

Scope and limits

Available navigation, account/admin pages, document views, search, folders, actions, workflows and CP layouts are covered by the action records below. Writes use disposable audit fixtures. No global AI settings, real users, credentials or existing documents were edited. Actions requiring external accounts, other roles, unavailable content types or unrelated add-ons are not claimed as tested.

Unrelated demo add-ons are unavailable in Angular for this scope: SA Inventory/Requests/MSA work queue, SA Accessibility, linked work tasks, media conversion, DLP controls, template rendering, portal and other optional extensions. CP is included. Baseline PDF/search failures were traced to malformed asset paths from linked build dependencies and received a separate packaging correction.
